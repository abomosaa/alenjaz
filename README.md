# الإنجاز | ALENJAZ 

## نبذة عن المشروع (About)
**الإنجاز (ALENJAZ)** هو موقع تعريفي (Landing Page) رسمي يعرض معلومات الشركة، الفروع المتاحة، أرقام التواصل المباشر، وروابط حسابات التواصل الاجتماعي لتسهيل وصول العملاء للخدمات[cite: 2].
